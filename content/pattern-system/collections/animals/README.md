# Animals / Animales

This collection contains 30 user-approved animal motifs using the `A####` base-design prefix and the standard Drielo technique suffixes: `-CS`, `-C2C`, `-TC`, `-LH`.

Examples: `A0001-CS`, `A0001-C2C`, `A0001-TC`, `A0001-LH`.

## Canonical artwork rule

The files in `reference-library/` are the source of truth. The compressed matrix archive was derived from the approved animal reference sheets in this project. Reference PNGs and source PNGs are generated deterministically from that archive.

Do **not** ask an image model to recreate an Animals motif when building a pattern. Do **not** replace a motif with a similar animal. Every sellable pattern must originate from the exact `A####` canonical matrix.

## Palette

All 30 motifs share one strict 24-colour DMC palette defined in `collection.json`. Pattern generation may simplify resolution per technique, but it may not introduce colours outside that palette.

## Grid profiles

- Master / Cross Stitch: 100 × 120
- C2C Crochet: 60 × 72
- Tapestry Crochet: 80 × 96
- Latch Hook / Rug: 60 × 72

The generated masters keep transparent backgrounds and safe margins so heads, ears, tails, feet and accessories are not cropped.

## Current state

Reference infrastructure and canonical artwork are ready. Technique products remain uncreated until product generation is explicitly requested. Page-1 lifestyle/cover assets are intentionally left pending.
