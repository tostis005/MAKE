# Florals / Florales

30 coordinated floral and botanical designs use the `F####` base-design prefix and the existing Drielo technique suffixes: `-CS`, `-C2C`, `-TC`, `-LH`.

Examples: `F0001-CS`, `F0001-C2C`, `F0001-TC`, `F0001-LH`.

## Canonical reference rule

The five files in `reference-sheets/` are the approved visual source of truth for this collection. Every entry in `designs.json` is pinned to an exact sheet and cell. Future canonical pattern sources must reproduce those motifs rather than generate substitutes.

All patterns use one strict 24-color collection palette plus transparency. Canonical source extraction must happen before technique-specific reduction, and all products stay non-renderable until the canonical source passes visual QA.

See `generation-rules.json` and `reference-sheets/manifest.json` before generating any Florals pattern.
